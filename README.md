✨ About the Project
A modern, responsive dashboard for Cairo University’s Faculty of Arts.
It centralizes academic departments, faculty news, student services, and campus resources into one interactive control panel.
This project was developed as a team effort by Mohammed Tarek and Eman Ibrahim, and was successfully showcased at Cairo University’s AI Conference (2025).

🚀 Features
🏛️ Faculty Overview — history, vision, and academic departments

📰 News & Announcements — latest updates and events

🎓 Academic Programs — undergraduate & postgraduate guides

🧑‍🎓 Student Services — schedules, portals, and activities

📊 Dashboard Interface — unified control panel for academic resources

📱 Responsive Design — optimized for desktop & mobile

🛠️ Tech Stack
HTML5 — semantic structure

CSS3 — custom styling & responsive design

JavaScript — interactive navigation

🌍 Deployment
Automatic deployment via GitHub Pages on every push to main.
